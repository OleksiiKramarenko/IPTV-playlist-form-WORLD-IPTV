# IPTV Playlist Builder

Каждый час собирает `playlist.m3u` из нескольких публичных плейлистов, оставляет только нужные группы
и только те потоки, которые реально отдают видео. Плейлист раздаётся по постоянному URL через GitHub Pages
(или raw.githubusercontent.com).

```
config.json ─► скачать источники ─► группы по правилам ─► объединить дубли ─► проверить потоки
                                                                                   │
playlist.m3u ◄── защита от «усыхания» ◄── лучшая ссылка на канал ◄── история проверок (health.json)
```

## Как это работает

1. **Источники** (`sources` в `config.json`) скачиваются параллельно. Упавший источник просто пропускается.
2. **Группы.** Названия групп из источников нормализуются (регистр, эмодзи) и сопоставляются с правилами `groups`
   по подстроке: `"🔴 Кинозалы 🔴"` и `"Кинозалы Kinowalk"` → `Кинозалы`. Группы из `exclude_groups`
   (VPN, региональные и т.п.) и группы без правила отбрасываются. Ссылки на файлы `.mp4/.mkv/...` тоже.
3. **Прошлый плейлист.** Опубликованный `playlist.m3u` тоже читается как источник — последний по приоритету.
   Канал, который источник перестал отдавать, остаётся, пока его поток работает; если канал есть и там,
   и там, старая ссылка становится запасной. Проверка, заглушки, `exclude_channels`, `exclude_groups` и
   удаление группы из `groups` действуют на такие каналы как на любые другие — мёртвое не накапливается.
   **Лист ожидания.** Канал, выпавший из плейлиста, ещё `check.retire_days` дней (по умолчанию 30)
   хранится в `retired.json` и проверяется каждый запуск: если за это время он снова заработал —
   возвращается в плейлист, иначе удаляется окончательно. Поэтому канал, который лежал пару недель,
   не теряется, даже если его уже нет ни в одном источнике.
4. **Дубли.** Один и тот же канал из разных источников (`Интер`, `Интер HD`, `Интер (2)`) склеивается
   в один канал со списком запасных ссылок.
5. **Проверка.** Каждая ссылка проверяется до реального видеосегмента: master-плейлист → вариант качества →
   свежий сегмент. HTML-заглушки, пустые и зацикленные плейлисты считаются нерабочими.
   **Видеозаглушки** («канал не в сети», «оплатите подписку», «недоступно в вашем регионе») тоже
   отсеиваются: это либо короткий законченный плейлист (`#EXT-X-ENDLIST`, меньше 5 минут), который
   плеер крутит по кругу, либо один и тот же ролик, который провайдер отдаёт сразу для многих каналов —
   если у `check.stub_min_channels` и более разных каналов байты сегмента совпадают, это заглушка.
   История такой ссылки обнуляется, поэтому `grace_fails` её не удерживает, а при наличии живого
   зеркала канал переключается на него.
6. **EPG и логотипы.** Из каждого XMLTV в `epg.urls` читается только список каналов (до первой передачи).
   Канал получает `tvg-id` из EPG: свой, если EPG его знает, иначе из `epg.aliases`, иначе по названию
   (только при однозначном совпадении). Пустой логотип заполняется иконкой из EPG.
7. **Выбор ссылки.** Для канала берётся рабочая сейчас ссылка с лучшей историей (доля успешных проверок
   за последние `history_size` запусков, затем задержка). Если сейчас все ссылки упали, но одна из них
   работала и падает не больше `grace_fails` раз подряд — канал остаётся, чтобы не мигать.
   Одна ссылка достаётся только одному каналу: если под разными названиями («Загородная жизнь» и «ЗЖ»)
   оказался один и тот же поток, остаётся канал из источника выше по списку, а второй берёт
   свою запасную ссылку или выпадает.
8. **Защита.** Если каналов меньше `min_channels` или меньше `min_ratio` от прошлого плейлиста —
   старый плейлист не перезаписывается, запуск в Actions падает (придёт письмо от GitHub).

## Структура

```
config.json                     источники, правила групп, настройки проверки и вывода
iptv/
  __main__.py                   CLI: python -m iptv [--config config.json] [--force]
  pipeline.py                   весь процесс сборки и защита от «усыхания»
  sources.py                    скачивание источников
  m3u.py                        разбор и запись M3U
  groups.py                     нормализация и сопоставление групп
  channels.py                   склейка дублей, запасные ссылки
  checker.py                    проверка потоков до сегмента
  stubs.py                      поиск видеозаглушек, общих для многих каналов
  health.py                     история проверок и выбор лучшей ссылки
  retired.py                    лист ожидания выпавших каналов
  epg.py                        подбор tvg-id и логотипов по EPG
tests/                          pytest
.github/workflows/update-playlist.yml
playlist.m3u                    результат (коммитится ботом)
```

`health.json` (история проверок) и `retired.json` (лист ожидания) хранятся в кэше GitHub Actions, а не в репозитории.

## Настройка (`config.json`)

| Ключ | Что делает |
|---|---|
| `sources[]` | `{name, url}` — публичные M3U. Порядок = приоритет: имя, группа и логотип канала берутся из первого источника |
| `groups[]` | `{name, match[]}` — группа в итоговом плейлисте и подстроки для поиска в названиях групп источников. Порядок = порядок групп в плейлисте; срабатывает первое подходящее правило |
| `exclude_groups[]` | подстроки, при которых группа отбрасывается всегда (проверяются до `groups`) |
| `exclude_channels[]` | каналы, которые не нужны. Сравнение по названию без учёта регистра, качества (HD/FHD) и номера копии: `"Интер"` уберёт `Интер`, `Интер HD`, `Интер (2)`, но не `Интер+`. `*` — любые символы: `"Интер*"` уберёт и `Интер+`, `"*футбол*"` — все каналы со словом «футбол». Пробелы и знаки при сравнении убираются, поэтому `"*нтв*"` поймает и «Ре**н ТВ**», а `"*рф*"` — «Мета**морф**ози»; для точности используйте `"нтв*"` (начинается с) или `"*рф"` (заканчивается на). Буквы должны быть в одной раскладке — слово, где смешаны латиница и кириллица (`pоссия` с латинской `p`), остановит сборку с ошибкой |
| `skip_vod_files` | отбрасывать прямые ссылки на видеофайлы |
| `check.timeout` / `check.workers` | таймаут проверки одной ссылки (сек) и число параллельных проверок |
| `check.history_size` / `check.grace_fails` | сколько последних проверок помнить и сколько неудач подряд прощать |
| `check.retire_days` | сколько дней перепроверять выпавший из плейлиста канал, прежде чем забыть его (`0` — не ждать) |
| `check.stub_min_channels` | у скольких разных каналов должен совпасть видеосегмент, чтобы считать его заглушкой (по умолчанию 3; `0` — выключить). Зеркала одного канала не считаются |
| `epg.urls[]` | XMLTV-файлы программы передач: пишутся в заголовок `url-tvg` и используются для подбора `tvg-id` и логотипов |
| `epg.aliases{}` | ручное соответствие «название канала → id в EPG» для каналов, которые не находятся по названию (например, латинские названия) |
| `epg.skip_groups[]` | группы, для которых EPG не подбирается (фильмы — у них нет телепрограммы) |
| `output.min_channels` / `output.min_ratio` | защита от публикации пустого или сильно урезанного плейлиста |

Добавить источник — дописать строку в `sources`. Новые группы, не попавшие ни под одно правило,
можно найти в логе Actions (`kept N/M entries`) или посмотрев группы источника:

```bash
curl -sL <url> | grep -o 'group-title="[^"]*"' | sort | uniq -c | sort -rn
```

## Запуск

Автоматически: каждый час, при изменении `config.json`/кода в `main` и вручную
(**Actions → Update IPTV Playlist → Run workflow**; галочка `force` отключает защиту от «усыхания»).

Локально:

```bash
python3 -m venv .venv && . .venv/bin/activate
pip install -r requirements-dev.txt
python -m pytest
python -m iptv            # пишет playlist.m3u и health.json
```

## Ограничения

- Проверка идёт с серверов GitHub (США). Потоки с гео-блокировкой могут проходить проверку, но не играть
  у вас — или наоборот. Поэтому группы с пометкой VPN исключены.
- Источники — неофициальные сборники публичных ссылок; доступность и законность конкретных каналов зависят
  от правообладателя и страны.
